# Arrowza Unity update — release note text

The Unity update starts a new game at Level 1. Levels, coins and results from the previous Kotlin version do not transfer. Your new progress, settings and rewards save normally. Optional ads offer an extra heart or hint; limited interstitial ads may appear between completed main levels. New app icon.
